# Content

Prose for the site, kept out of code so a word change is a Markdown edit.

- `chapters/<year>.md`: each year's title and opening quote (front matter). Drafts from
  the design prototype; Jamie rewrites them.
- `series/<slug>.md`: the line under each series heading.
- `poap.md`: POAP the company, a sourced summary of `research/poap-company.md` in
  `poap-archive`.
- `writing.md`: the introduction to Jamie's writing about POAP.
