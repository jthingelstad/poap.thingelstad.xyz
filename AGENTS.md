# poap.thingelstad.xyz

The public site for Jamie's POAP time capsule. Read `../poap-archive/BRIEF.md` (or
https://github.com/jthingelstad/poap-archive/blob/main/BRIEF.md) before designing anything.

- Data comes from `jthingelstad/poap-archive`. Treat that repo as the source of truth and
  read it; do not copy raw captures here beyond what the site needs to ship.
- This repo is public. Never commit personal email, private notes, credentials or `.env`
  files. Jamie's private notes about the POAP team are not available to this site.
- Naming individual collectors on the site is Jamie's decision, not yet made. Ask.
- Private drops (`private: true`) are unlisted, not secret; show them like any drop.
- Follow `~/Projects/AGENTS.md` for AWS. The project bucket
  `poap-archive-999153317627-us-east-1` is private; hosting (domain, CloudFront, deploy
  path) is not decided yet.
- Moment photos are lost upstream. Do not hotlink `assets.poap.xyz` or any POAP host for
  the site; ship copies of the artwork from the archive.
- "POAP KINGS" is a Clash Royale clan, unrelated to POAP.
